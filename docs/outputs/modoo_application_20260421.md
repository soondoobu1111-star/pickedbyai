**[문제: 보이지 않는 제품과 콘텐츠]**

그런데 AI 답변에 자기 제품·콘텐츠·브랜드가 보이기를 원하는 수억 명에게는 확인할 방법이 없습니다. "내 제품이 5대 AI 중 어디에 뜨고 어디에 안 뜨는가?" 이 질문에 답할 도구가 존재하지 않습니다. GEO(Generative Engine Optimization) 도구는 2026년 현재 전 세계에 24개 존재하지만, 전부 월 $500 이상의 기업 전용이며 **5대 AI를 모두 커버하면서 제품과 콘텐츠를 동시에 포괄하는 플랫폼은 0개**입니다.

*(← Winston Cycling 1회: 크리에이터 전용 0개)*

**[핵심 고통]**

- 전체 디지털 제품의 70%가 AI가 인식할 수 있는 Product 스키마 없음
- 내 제품이 AI 추천에서 빠지는 이유를 알 수 없고, 고칠 방법도 없음
- "AI 마케팅"은 알겠는데, AI가 실제로 내 제품을 아는지 확인 불가
- 경쟁 제품은 AI에서 추천되는데 내 제품만 안 보이는 이유를 모름

**[타이밍]**

2005년 Google Analytics가 없던 시절 웹사이트 운영자들이 "내 사이트가 검색에 뜨는지" 몰랐던 것과 동일한 상황입니다. 그 공백을 채운 것이 Google Search Console이었고, 지금 AI 추천 영역에 동일한 공백이 존재합니다.

## [Section 3] 솔루션

*(목표: 1000자 이내 — Winston Symbol + Salient 원칙 적용)*

**[솔루션 개요]**

**pickedby.ai**는 누구나 URL/제품명/콘텐츠 주소를 입력하면 **5대 AI(GPT·Gemini·Claude·Grok·Perplexity)**가 해당 **제품 또는 콘텐츠**를 얼마나 인식하고 추천하는지를 0~100점으로 즉시 측정해주는 플랫폼입니다. 측정 단위는 SaaS 제품, Gumroad 템플릿, 블로그 글, YouTube 채널, 뉴스레터, 퍼스널 브랜드 등 **AI 답변에서 발견되기를 원하는 모든 것**입니다. (베타 단계는 무료 범위 내 운영을 위해 Gemini+Perplexity 2엔진으로 시작, 정식 v2.0에서 GPT·Claude·Grok 3개 엔진 추가해 5대 전체 가동)

**[3단계 작동 원리]**

**Step 1 — 측정 (10초, 무료, 가입 불필요)**
- URL 입력 → 5대 AI(GPT·Gemini·Claude·Grok·Perplexity)에 "best {카테고리}" 쿼리 자동 실행
- Recognition(35점) + Category Ranking(35점) + Co-Recommendation(20점) + Web Authority(10점) = 4차원 100점 체계
- 결과: "당신의 제품은 Gemini·Claude에는 인식되지만 GPT·Grok·Perplexity에는 없습니다" 같은 엔진별 세부 진단

**Step 2 — 배지 (Symbol — 크라운 🏆)**
- 점수별 Gold(81+) / Silver(61+) / Bronze(36+) "PICKED BY AI" 배지 발급
- 배지를 Gumroad·개인 사이트에 embed → AI가 신뢰 신호로 학습 → AI 추천 자연 상승
- **Flywheel**: 배지 embed → AI 크롤링 → 학습 데이터 → 더 많은 AI 추천 → 더 많은 배지 수요

*(← Winston Cycling 2회: Flywheel이 경쟁자가 복제할 수 없는 이유)*

**Step 3 — 최적화 (매일 자동)**
- 매일 KST 자정 5대 AI 자동 재측정 → 점수 변화 감지
- Daily Pulse: "어제 Gemini에서 당신이 사라졌지만 Claude가 새로 추천하기 시작했습니다. 이렇게 하면 Gemini도 돌아옵니다"
- Action Items 3가지 자동 생성: 오늘 해야 할 최적화 액션
- 3탭 차트(일간/주간/월간): 점수 추이로 마케팅 효과 측정

**[핵심 차이]**
기존 SEO 도구는 구글 랭킹을 분석합니다. pickedby.ai는 AI가 실제로 추천하는지를 직접 묻습니다. "구글에서 1위"와 "AI에서 추천"은 완전히 다른 측정입니다.
