### 4.2 Etsy/Gumroad 셀러의 실제 관심사

리서치 결과, 2026년 이 셀러들의 관심사:
1. **매출 늘리기** — "how to get more sales on Etsy"
2. **SEO 태그/키워드** — Etsy 검색 알고리즘 최적화
3. **AI로 리스팅 만들기** — EverAlice Studio 같은 도구 사용
4. **트래픽 소스** — Pinterest, TikTok에서 Etsy로 유입
5. **디지털 제품 아이디어** — 뭘 팔아야 하나

**"AI가 내 제품을 추천하는가?"는 그들의 관심사 목록에 아직 없다.**

이것은 좋은 소식일 수도, 나쁜 소식일 수도 있다:
- **좋은 소식**: 시장을 교육하면 선점 가능 (카테고리 크리에이터)
- **나쁜 소식**: 존재하지 않는 수요를 만들어야 함 (CAC 극도로 높음)

```

필터: 팔로워 500~10K, 최근 7일 활동, 영어 사용
```

**DM 템플릿** (직접적, 개인화):
```
Hey [이름]! I saw your [제품명] on Gumroad — love it.

Quick question: have you ever checked if ChatGPT recommends
your product when someone asks for [카테고리]?

I built a free tool that checks this in 10 seconds.
Want me to run yours? No sign-up needed.
```

기대: 30명 DM → 5~8명 응답 → 3~5명 실제 체크


## 7. 전략적 의사결정 — CEO 판단 필요

### 질문 1: 타겟 유저 재정의 필요한가?

```
현재 타겟: Gumroad/Etsy 디지털 크리에이터
문제: "AI Visibility"를 아는 크리에이터 = 거의 0명
대안 A: 타겟 유지 + 시장 교육 (느리지만 선점)
대안 B: 타겟을 "마케터/SEO 전문가"로 전환 (시장 존재, 경쟁 치열)
대안 C: 양쪽 동시 — 크리에이터용 무료 + 마케터용 유료
```

**CPO 의견**: 대안 C 권고. 무료 체커로 크리에이터 유입 + Pro 플랜으로 마케터 수익화. 하지만 **첫 10명은 크리에이터**에서 먼저 검증.

### 질문 2: PH 런치 타이밍

```
현재 계획: 이메일 50개 달성 후 PH 런치
문제: 이메일 0개 → PH 무기한 연기
대안: 이메일 게이트 제거, 2주 내 PH 런치
이유: PH 자체가 인디해커/크리에이터 채널. 대기 이유 없음
```

**CPO 의견**: PH 런치를 4월 마지막 주로 앞당기기 권고.

### 질문 3: Hero 카피 변경

```
현재: "AI Visibility Score for Digital Creators"
제안: "Does ChatGPT recommend your product?"
```

**CPO 의견**: 즉시 변경 권고. 지금 카피는 이미 아는 사람용. 변경 카피는 모르는 사람도 클릭함.
