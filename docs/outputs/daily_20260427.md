### 수정 내용
1. **`supabaseEnv.ts`** — `SUPABASE_ANON_KEY_PROD` + `getAnonKey(env)` 추가
   - anon key(공개 JWT)를 환경별 하드코딩 → secret 오염 불가능
2. **`index.ts`**
   - `verifyToken`: prod/staging 양쪽 시도 → `getSbUrl(env)` 단일 환경만
   - `SUPABASE_ANON_KEY` Bindings → optional (deprecated)
   - 모든 `c.env.SUPABASE_ANON_KEY` → `getAnonKey(c.env)` 교체 (3곳)
   - 로컬 `SUPABASE_ANON_KEY_STAGING` 상수 제거 → `supabaseEnv.ts` 통합
   - `ENVIRONMENT` 필드 `Bindings` 타입에 추가
