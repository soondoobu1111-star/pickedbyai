# 경쟁사 검색 vs. 내 도메인 전략
> 작성일: 2026-04-15 | 작성: CPO Agent

---

## 배경

pickedby.ai는 현재 대시보드에서 **경쟁사 포함 모든 제품**의 AI 가시성 점수 확인을 허용하고 있다.
Google Search Console API 검토 결과, Search Console은 **내 도메인 소유자에게만** 데이터를 제공하는 구조임을 확인.
이 구조가 pickedby.ai의 장기 방향성("The Google Stack for AI")과 일치하는지 점검이 필요했다.

---

## 각 방식에서 얻을 수 있는 것

### 경쟁사 검색

| 얻는 것 | 설명 | 액션 가능 여부 |
|---------|------|--------------|
| 경쟁사 AI 가시성 점수 | 내 제품과 비교 수치 | ❌ 상대 점수를 알아도 내가 할 일 없음 |
| 경쟁사 AI 추천 여부 | 어떤 AI가 경쟁사를 추천하나 | ❌ 내 개선 방향과 직접 연결 안 됨 |
| 경쟁사 언급 출처 | 어느 사이트가 경쟁사 점수에 기여 | △ 참고는 되나 내가 그 사이트에 등록되어 있는지는 별도 확인 필요 |

**핵심 문제:** 경쟁사 데이터는 정보(information)이지 인사이트(actionable insight)가 아님.
방문 → 검색 → "오 그렇구나" → **이탈**. 재방문 이유가 없음.

---

### 내 도메인 검색

| 얻는 것 | 설명 | 액션 가능 여부 |
|---------|------|--------------|
| 내 AI 가시성 점수 | 내가 AI에 어떻게 인식되나 | ✅ 점수 올리기 위한 콘텐츠/llms.txt 개선 |
| AI가 나를 추천하는 맥락 | 어떤 카테고리로 인식되나 | ✅ 포지셔닝 수정 가능 |
| AI 언급 출처 | 내 점수에 기여하는 사이트 목록 | ✅ 해당 사이트 집중 투자 |
| 점수 추이 | 개선 활동 후 변화 확인 | ✅ **재방문 이유** 생성 |
| Verification 연동 | 소유자 증명 → Phase 2 기반 | ✅ 유료화 경로의 출발점 |

---

## 유저 흐름 비교

```
경쟁사 검색 플로우
─────────────────
방문 → 경쟁사 검색 → 점수 확인 → 이탈
재방문률: 낮음 / 유료 전환 경로: 없음

내 도메인 검색 플로우
────────────────────
방문 → 내 제품 검색 → 점수 낮음 확인
→ 왜 낮은지 분석 → llms.txt 추가 → 재검색(재방문)
→ 점수 변화 확인 → Verification 연동
→ Phase 2 베타 등록 → 유료 전환
재방문률: 높음 / 유료 전환 경로: 직접 연결
```

---

## Google Search Console과의 비유

| 구분 | Google Search Console | pickedby.ai |
|------|-----------------------|-------------|
| 경쟁사 데이터 | ❌ 불가 (소유권 필수) | 현재 허용 중 |
| 내 도메인 데이터 | ✅ 핵심 기능 | ✅ 핵심 기능 |
| 재방문 이유 | 내 사이트 성과 추적 | 내 AI 점수 추적 |
| 유료화 근거 | 더 많은 데이터/기능 | 더 많은 데이터/기능 |

## 결정 방향 (제안)

### 단기 (현재 ~ PAY-01 이전)
- 경쟁사 검색 **유지** — 신규 유저 진입 장벽 낮추는 역할
- 단, 경쟁사 체크 결과 하단에 **"내 제품은 어떤가요?" CTA** 추가
- 가입 후 첫 화면은 **내 도메인 체크 유도** UX로 개선

### 중기 (PAY-01 이후)
- 경쟁사 검색 → **유료 기능으로 전환**
- 무료: 내 도메인 1개 (Search Console 포지셔닝 완성)
- 유료: 경쟁사 최대 N개 + 비교 리포트

## 즉시 실행 항목

| 우선순위 | 작업 | 예상 임팩트 |
|----------|------|------------|
| P1 | 경쟁사 체크 결과 하단 "Check your own product" CTA 추가 | 내 도메인 등록 전환율 ↑ |
| P1 | 대시보드 온보딩 — 첫 진입 시 내 제품 입력 유도 문구 강화 | 활성 유저 ↑ |
| P2 | 경쟁사 탭 서버사이드 rate limit 강화 (현재 클라이언트 사이드) | API 비용 통제 |
| P3 (PAY-01 이후) | 경쟁사 체크 유료화 | 수익화 |

## 참조
- Google Search Console API 할당량: `limits` 페이지
- URL Inspection: 소유 도메인만 가능, 라이브 크롤 불가
- Search Analytics: 소유자 OAuth 인증 필수
