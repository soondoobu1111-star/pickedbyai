## 6. 재발 방지책 (즉시 적용)

### 🔴 Rule 0 — SNS 자동화 절대 금지 (신규 추가)
```
외부 SNS 플랫폼(X, LinkedIn, Instagram, Reddit 등) 자동 포스팅·댓글·팔로우 절대 금지.
X API 공식 OAuth 연동조차 CEO 명시적 승인 + 플랫폼 ToS 검토 필수.
위반 시 계정 정지 → 복구 불가 리스크.
```

### 🔴 Rule 1 — 외부 플랫폼 기능 배포 전 체크리스트 (신규)
```
모든 외부 플랫폼 연동 기능 배포 전 반드시 확인:
□ 해당 플랫폼 ToS/API 정책 링크 확인했는가?
□ 자동화(봇) 관련 조항이 있는가?
□ 위반 시 패널티가 계정 정지인가?
□ 공식 API를 사용하는가, 비공식 방법인가?
□ CEO가 위험성을 인지하고 명시적으로 승인했는가?
```

### 🟡 Rule 2 — 채널 분산 원칙 (신규)
```
단일 SNS 채널에 의존 금지.
주력 채널 + 백업 채널 최소 2개 유지.
현재: LinkedIn(주) + Indie Hackers(보조)
```

### 🟡 Rule 3 — 자동화 도구 배포 프로세스 (강화)
```
자동화 도구는 스테이징 배포 → 72시간 관찰 → CEO 최종 확인 후 프로덕션.
(기존 스테이징→승인→프로덕션보다 관찰 기간 추가)
```
