## 세션 4 — Google Search Console API 분석 + 경쟁사 전략

### Google Search Console API 핵심 정책

| 항목 | 내용 |
|------|------|
| 인증 | OAuth 2.0 필수, 도메인 소유자만 데이터 접근 가능 |
| Search Analytics | 클릭/노출/CTR/순위, 최대 25,000 rows, 상위 결과만 반환 |
| URL Inspection | 인덱스 상태만 확인 가능, 라이브 크롤 불가 |
| 할당량 | Search Analytics 1,200 QPM/사이트, URL Inspection 2,000 QPD/사이트 |

**핵심 시사점:** 경쟁사 도메인 데이터는 Search Console API로 원천 불가 → 내 도메인 전용 전략과 자연스럽게 맞아 떨어짐

### 경쟁사 검색 vs 내 도메인 — 최종 방향

```
단기: 경쟁사 검색 유지 (신규 유저 진입 훅)
      → 경쟁사 결과 하단 "Check your own product" CTA 추가 (미구현)
중기: 경쟁사 체크 유료 기능 전환 (PAY-01 이후)
```
