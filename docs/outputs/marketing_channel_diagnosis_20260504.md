## 1. 진단 (marketing-psychology 7개 mental model 적용)

### Model 1 — Theory of Constraints (병목 이론)
**적용**: LinkedIn 반응 0의 진짜 병목은 콘텐츠 품질이 아니라 **0 followers / 0 first-degree network**. 알고리즘은 첫 1시간 dwell + initial engagement로 도달을 결정. 제로 베이스 계정에서 5개 게시는 "콘텐츠 5번 다듬기"가 아니라 "병목(네트워크)"을 건드리지 않은 것.

**증거**: 5개 × 24일 = 평균 4.8일 1회 = 알고리즘 기억 휘발 사이클 외부.

**반증 가능성**: LinkedIn DM 직접 outreach로 first 50 followers 확보 후 동일 콘텐츠 게시 → 반응 측정. (지금까지 시도 0)

---

### Model 2 — Mimetic Desire (모방 욕구)
**적용**: "사람은 다른 사람이 원하는 것을 원한다." Reddit 댓글 9개 = 0 social proof 누적. 댓글은 thread 안에서만 보이고 24h 후 휘발. 카르마 106도 dataset/portfolio가 아니라 점수일 뿐 — 누구도 "이 사람 흥미롭다" 추적 못함.

**시사점**: 댓글-기반 카르마 빌딩은 **mimetic 자산을 0% 누적**. Indie Hackers 프로필은 영구적 milestones·MRR·posts 누적 → mimetic asset.

---

### Model 3 — Compounding (복리 효과)
**적용**: LinkedIn은 매 게시가 휘발 (3-day half-life). 블로그 SEO 18편은 매일 누적 (검색 노출 = 평생 자산). 우리가 24일간 LinkedIn에 쏟은 시간을 블로그/programmatic SEO에 넣었으면 long-tail keyword 50~100개 indexing 가능.

**Pareto 보강**: 18편 블로그 중 상위 20%(3-4편)가 80% 트래픽. 그것만 우선 강화.

---

### Model 4 — Curse of Knowledge (지식의 저주)
**적용**: 우리 LinkedIn 카피는 "AEO/AI Visibility Score/5-engine prescription" 등 **이미 문제를 아는 사람의 언어**. 일반 LinkedIn 사용자(마케터/임원)는 "AEO가 뭔데?"부터 시작. 처음 3초에 "왜 이게 내 문제인가?" 인지 못 함 → 스크롤.

**검증**: 게시물 첫 줄을 "Your product is invisible to ChatGPT. Here's why." 같은 problem-first hook으로 바꾸고 다시 측정 가능.

---

### Model 5 — Reciprocity Principle (호혜성)
**적용**: LinkedIn 5개 게시 모두 "발표/공유" 톤 — give 0. 호혜성 없으면 follow/like 동기 0. Indie Hackers 컬쳐는 "내 학습/실패/숫자 공개" = give. 그래서 같은 콘텐츠라도 IH가 LinkedIn보다 ROI 높음.

**액션**: 모든 게시 첫 paragraph에 "free takeaway" — "여기 우리 score baseline 가드 코드, 가져가서 쓰세요" 식으로 reciprocity trigger.

---

### Model 6 — Hick's Law / Activation Energy
**적용**: Reddit 댓글에서 도메인 0 정책 = **CTA가 없음**. 댓글 본 사람이 우리를 찾아오려면 username 클릭 → bio 확인 → 외부 URL 클릭 = 3단계 friction. Activation energy 너무 높음. → 카르마는 오르지만 트래픽 0.

**해결**: Reddit username의 bio에 "I work on pickedby.ai (free AEO score)" 한 줄 — 댓글 본문 도메인 0 룰 위배 0, but bio는 자기소개 영역 = 안전. (CEO 확인 필요)

---

### Model 7 — Survivorship Bias (생존자 편향)
**적용**: "LinkedIn에서 indie SaaS 성공한 사람" 사례 모방 위험. 보이는 성공은 이미 5K+ followers 가진 사람들의 후행지표. 우리는 prerequisite (네트워크) 미충족. 후행지표를 선행지표인 줄 알고 따라하면 24일 0건 결과 정확히 발생.

**시사점**: 채널 선택의 1차 기준은 "성공 사례 많은가"가 아니라 **"신규/0-network 친화도 높은가"**.

---

## 2. 가설 검증

### 가설 #1 — 타겟 불일치 (★★★★★ 가장 유력)
- **Evidence**: indie SaaS/AEO 키워드 검색 시 활성 커뮤니티는 Indie Hackers, HN, r/SaaS, r/EntrepreneurRideAlong, Dev.to. LinkedIn은 B2B 엔터프라이즈/마케터 풀. 우리 ICP("크리에이터·소상공인·indie founder")의 LinkedIn 농도는 5% 미만 추정.
- **반박**: LinkedIn에도 indie founder 있긴 함. 단, 네트워크 효과 없으면 도달 불가 = 사실상 0.
- **결론**: ICP 채널 농도 차이 = 10배 이상. 채널 자체 잘못 선택한 것.

### 가설 #4 — 빈도 부족 / 알고리즘 사망 (★★★★☆ 유력)
- **Evidence**: LinkedIn 알고리즘은 "마지막 게시 후 7일 이내" 기준 신선도 점수 부여. 4-5일 1회 페이스도 빈도 자체로는 OK인데, **첫 1시간 engagement < 5건이면 알고리즘이 그 이후 도달을 0에 가깝게 차단**. 5게시 모두 첫 1시간 0 engagement 추정 → death spiral.
- **반박**: 빈도가 매일이라도 0 engagement면 결과 동일.
- **결론**: 빈도 자체보다 **첫 1시간 engagement seeding**이 진짜 변수. 봇 동원 X / 친구 동원만 가능.

### 가설 #2 — 콘텐츠 톤 (★★★☆☆ 부분 유력)
- **Evidence**: Curse of Knowledge로 검증. 사실 검증 위주 = LinkedIn 알고리즘이 좋아하는 "personal story / contrarian take" 외부.
- **반박**: 같은 톤이라도 네트워크 있으면 일정 도달 발생.
- **결론**: 네트워크 0 + 톤 mismatch = 곱연산으로 0. 톤만 바꿔도 반응 0 가능성 높음.

### 가설 #3 — 포맷 (★★☆☆☆ 약함)
- LinkedIn은 long-form 친화. 우리 게시도 long-form. 포맷 자체는 문제 아님.

### 가설 #5 — 시점 (★☆☆☆☆ 무시 가능)
- 한국 시간 08:00 KST = 미국 EST 19:00 (전날 저녁) = 오히려 좋은 시간대. 시점은 변수 아님.
